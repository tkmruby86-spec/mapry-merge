# mapry-merge (mapry Point Cloud Merger)

株式会社マプリィ（mapry）のLiDAR端末（mapry LA03等）で取得した分割PCDデータ群と移動軌跡CSV（`local_path.csv`）を、姿勢クォータニオンの球面線形補間（Slerp）および位置補間によって単一のグローバル座標系点群（`.ply`）へ結合・出力するPythonツールです。

公式クラウドや専用アプリを介さず、**ローカルPC上で直接CloudCompareやMeshLab、Blender、GISソフト等で扱えるPLYファイルを作成したい**方向けに作成されています。

---

## 動作要件

- **OS**: Windows 10/11, macOS, Linux
- **Python**: 3.8 以上
- **必須ライブラリ**:
  - `numpy`: バイナリPCDの高速読み込み・配列演算・PLY構造の生成
  - `pandas`: 軌跡データ（`local_path.csv`）の読み込み
  - `scipy`: クォータニオン姿勢の球面線形補間（`Slerp`）および位置補間（`interp1d`）

---

## セットアップ

ターミナル（Mac）またはコマンドプロンプト（Windows）を開き、依存パッケージをインストールします。

```bash
pip install -r requirements.txt
```

---

## 入力データのディレクトリ構成

対象フォルダ（例: `20260619_123157`）の直下に以下の構造でデータが保存されている必要があります（通常、端末から取得したままの構成です）。

```text
20260619_123157/
└── lidar/
    ├── local_path.csv       ← 軌跡データ（必須: timestamp, pos_x..z, rot_x..w）
    └── pointcloud/          ← PCDファイル群が格納されているフォルダ
        ├── 20260619_123157_0001.pcd
        ├── 20260619_123157_0002.pcd
        └── ...
```

## 使い方

### 1. Windows の場合（最も簡単）

1. `run_windows.bat` に、処理したいデータフォルダ（例: `20260619_123157`）を**ドラッグ＆ドロップ**します。
2. または `run_windows.bat` をダブルクリックするとフォルダ選択ダイアログが表示されるので、フォルダを選択します。
3. 処理が完了すると、対象フォルダと同じ階層に `forest_combined_<ID>.ply` が出力されます。

### 2. コマンドライン（Mac / Linux / Windows）の場合

```bash
# 基本的な使い方（データフォルダを指定）
python mapry_merge.py /path/to/20260619_123157

# 出力先ディレクトリを指定する場合
python mapry_merge.py /path/to/20260619_123157 -o /path/to/output_dir

# 引数を指定せずに実行した場合（ダイアログまたは入力プロンプトが起動します）
python mapry_merge.py
```

## 内部処理の概要

1. **軌跡データの読み込みと補間器の生成**  
   センサーの移動軌跡 `local_path.csv` を読み込み、各点のタイムスタンプに合わせてセンサー位置と姿勢（クォータニオン）の連続補間関数を生成します。
2. **局所座標からグローバル座標への変換**  
   各PCDバイナリ（24バイト構造: x, y, z, intensity, timestamp_sec, timestamp_nsec）から点群を読み出し、対応する時刻の位置・回転を適用して絶対座標系へ射影します。
3. **点群統合とPLY出力**  
   全スキャン点群を統合し、CloudCompareやMeshLabで直接開けるバイナリ形式のPLY（`x`, `y`, `z`, `intensity`）として書き出します。

---

## Mac ユーザーへの注意点

生成される `.ply` ファイルは大容量（数百万〜数千万点）になるため、macOSのFinderが「アイコンプレビュー」を生成しようとして高負荷になり、Macの動作が重くなる場合があります。  
Finderの表示オプション（`Cmd + J`）で **「アイコンプレビューを表示」のチェックを外しておくこと** を推奨します。
